## 本轮实施补充决定

- 2026-10-23：用户确认目前没有可用对话模型，并明确要求“先在项目中写死模拟的”。因此本轮加入明确标注的本地模拟模型，先验证引导、RAG、页面与 MCP 流程；真实 OpenAI 兼容配置和调用能力仍须交付。模拟模型不作为真实模型连接、生成质量或引用证据质量验收通过的依据。
- 同日实测本机 ES Basic 许可拒绝原生 RRF（403）。用户明确确认采用 ES 执行 BM25/kNN、Java 端 RRF 融合；架构决定同步更新至 ADR-0006，两路查询仍须保持内容权限与文档状态过滤。

## 待验收场景

- 两用户及共享知识库所有者/编辑者/查看者/非成员，覆盖原文件访问、关联、删除及撤权。
- 扫描与文字混合 PDF、中文 OCR、表格行列关系、单页失败、整份可用与索引发布。
- 队列饱和、单知识库和全局并发、重启恢复。
- 过滤分页、引导两轮/跳过/故障、会话模式和所选上下文恢复、RAG 最终拒答替换与真实引用质量。
- 原始 PDF 页面定位、文本定位、Office 位置、授权新页打开/下载。
- 真实命名模型连接、模型失败及可选重排，非管理员配置隔离。
- 标准 MCP 客户端初始化/发现/调用，凭证过期/撤销/限流/总开关/权限变化与调用记录隔离。
- 知识库和文档软删除/恢复、30 天边界、手动彻底删除、无有效引用字节回收及存量数据升级。
