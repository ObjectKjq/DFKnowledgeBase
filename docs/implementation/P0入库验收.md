## 范围和限制

入库 HTTP 旅程使用真实业务编排、解析器与线程池；文件存储、授权、向量/ES 边界使用替身。真实 MySQL 用于持久状态和存量升级，真实 OCR 用于中文扫描页；这些结果不能替代后续真实授权、文件存储、向量及 ES 的整条旅程。恢复测试重建调度实例及数据库会话，尚未通过终止实际后端 JVM 验证进程重启。

OCR 存在识别质量限制。大字号的混合中英语言模式出现误识别，正常正文约 13pt 样例通过；安装引擎不保证任意扫描质量或任意表格结构均正确。分页文本保留实际页码；Office 不承诺原排版还原，扫描/无边框 PDF 表格依赖可辨别的列间隔。

ES source 字段保持不变，OCR 与工作表等元数据从 MySQL 权威分块加载，不改现有 strict mapping。测试未改业务数据库或现有 ES 索引。
