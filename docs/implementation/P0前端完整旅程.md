## 交付范围

#23 使用独立分支 `codex/p0-frontend`，先交付管理切片 `4cc799e`，随后同步 #22、#24 的完整后端契约。前端 API 均从真实 Spring Boot OpenAPI 经 `openapi2ts` 生成，临时 schema 导出测试和配置均已恢复。

- 命名对话/重排模型真实增删改、连接测试、状态/原因/时间；密钥不回显，更新可留空保留或明确清除。本地模拟标识明确表示非真实生成。
- 实例管理员可保存全局/单知识库入库并发、MCP 总开关和每凭证调用上限；普通用户不展示实例设置入口，直接访问也只提供联系管理员提示。
- 知识库回收站、保留成员恢复、再次确认彻底删除；文档格式列与再次确认彻底删除。所有者/编辑者/查看者仍按真实成员关系呈现操作。
- 有权知识库每 5 秒刷新；首页入口为上传文档、向知识提问、连接 AI 智能体。
- 四种检索模式、命名模型选择、范围多选、格式/上传时间叠加过滤、20 条分页、高亮/实际命中/相关性/OCR/定位、空结果与索引中提示。分页保持原轮次查询和过滤快照。
- 会话选择有序保存、切换会话恢复自身状态、新会话重置默认模式/全部范围/过滤/上下文；每次发送固定独立快照，普通检索采用后端自动消息持久化，不再重复写消息。
- 引导推荐选项与自由输入、两轮状态恢复、随时跳过、模型故障原因及混合结果。所选上下文可逐分块勾选、调整和清空，RAG 请求携带所选分块和模型，失败重试沿用原问题与原快照。
- 流式生成仍标记暂定内容，最终拒答完整替换正文和引用；历史答案保留，失效引用打开时说明不可用。
- PDF 使用授权下载的原始字节并跳页；TXT/Markdown 展示授权原文件全文并按偏移定位；Office 展示按原文顺序的完整解析分块及页/幻灯片/工作表。所有格式提供重新授权的新页打开/原文件下载；PDF 对象 URL 在关闭或切换时回收。
- MCP 真实凭证创建/工具开关/1～365 天期限（默认 90）/即时撤销/本人调用记录分页/管理员中文汇总统计。完整令牌只在创建结果临时展示，关闭后清除，不进入浏览器存储；接入说明使用当前实例地址。
- 已移除 MCP/模型假连接测试、演示凭证、假调用记录、向量切换、档位、图片工具及全部 `src/mock`；共用 store 仅保留临时交互，不持久化业务数据。
