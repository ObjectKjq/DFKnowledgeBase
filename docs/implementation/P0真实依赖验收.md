## 真实联调发现与修复

第二轮实际 `/api/system/auth/login` 返回 401，应用日志显示请求在进入认证服务前被登录拦截。此前 HTTP 装配均使用空 context-path，未覆盖默认 `/api` 部署；SaRouter 的排除路径没有剥离该前缀。

修复为全路径注解鉴权拦截器，加上通过 MVC `excludePathPatterns` 排除公开路径的单独登录检查；保留精确 `/mcp` 独立凭证认证，MCP 管理路径仍受网页登录约束。实际 `/api` 完整旅程随后全部通过。该问题属于产品缺陷，未通过改变测试 context-path 或绕过身份服务掩盖。

第一轮 ES 索引准备曾误把 HTTP 模板中的 `{{esUrl}}` 当作 JSON 起点；这是验收脚本错误，已改为独立 JSON 行定位，不计为产品失败。
