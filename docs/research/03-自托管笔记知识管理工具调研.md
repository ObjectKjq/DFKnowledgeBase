# 自托管笔记 / 知识管理 / Wiki 工具调研

> 调研目的：为「可本地化部署的知识库平台」（支持关键字、图片、向量搜索与 RAG，提供网页客户端与 MCP 服务端，目标用户为学生与工作者）提供竞品参考。

> 信息源优先级：官方文档 / GitHub README / 官网。调研时间：2026-10。

## 二、各工具要点

### 1. SiYuan（思源笔记）

- **定位与用户**：面向个人的知识管理工具，主打「块级」编辑与本地优先，用户以中文社区的学生、知识工作者为主（[官网](https://b3log.org/siyuan/?lang=cn)）。
- **检索能力**：全局搜索基于 SQLite FTS5 虚拟表，因分词器区分大小写而构建 `blocks_fts`（按字符原样分词）与 `blocks_fts_case_insensitive` 两张虚拟表，按字符分词对中文单字搜索友好；查询语法支持 AND / OR / NOT 等操作符（[官方查询语法文档](https://siyuan-note.apifox.cn/siyuan/blocks/20220415190432-r3xqn3r)；[数据模型中 `blocks_fts` 为 FTS5 external content 虚拟表](https://deepwiki.com/siyuan-note/siyuan/2.2-data-model-and-storage)）。v3.7.0 起**内置 AI embeddings 语义搜索**（[Gitee 官方发行版](https://gitee.com/siyuan-note/siyuan/releases)、[版本说明镜像](https://winterflow.io/catalog/siyuan/releases/)）。图片内容搜索未见。
- **AI 能力**：v3.7.0 大版本起内置 AI Agent 体系（AI 智能体侧栏、CLI 可供 Claude Code 等直接调用、插件可注册 MCP 工具、多模型设置）（[3.7.0 更新解析](https://www.bilibili.com/video/BV1GtTw67E8d/)）；**内置 MCP Server**，`POST /mcp` 内核端点暴露 31 个 MCP 工具（[Rapid7 漏洞库](https://www.rapid7.com/db/vulnerabilities/cve-2026-66012/)）。**安全注意**：v3.7.2 修复了 /mcp 端点的越权漏洞（CVE-2026-66012，匿名读者可调用含文件读写在内的工具），自部署时务必升级（[SentinelOne 漏洞库](https://www.sentinelone.com/vulnerability-database/cve-2026-66012/)）。
- **KM 强项（可借鉴）**：块级双向链接 / 反链 / 关系图、闪卡（FSRS 间隔重复）、内置数据库（多维表格）、剪藏、大纲式文档树。
- **部署 / 许可证 / 社区**：Docker 与桌面端部署、数据本地存储；[AGPL-3.0 开源](https://github.com/siyuan-note/siyuan)；GitHub 25k+ stars，中文社区（链滴）活跃，2026 年仍在高频迭代（v3.7.x）（[App Store 版本记录](https://apps.apple.com/cn/app/%E6%80%9D%E6%BA%90%E7%AC%94%E8%AE%B0/id1583226508)）。

### 2. Outline

- **定位与用户**：面向团队的结构化知识库 / Wiki，适合企业内部文档协作（实时协作、评论、权限）。
- **检索能力**：基于 PostgreSQL 全文搜索，支持关键字、`-keyword` 排除、精确短语、OR 操作符（[官方文档](https://docs.getoutline.com/)）。未见内置向量搜索与图片内容搜索。
- **AI 能力**：AI answers 功能（检索页直接返回答案 + 来源引用 + 反馈投票）仅在 Cloud 与授权自托管版本提供；**提供官方内置 MCP server**：自托管实例在域名后追加 `/mcp` 即可接入，Streamable HTTP 传输、OAuth / API key 认证，官方文档直接给出 `codex mcp add outline --url ...` 接入示例（覆盖 Codex / Claude Code / Cursor 等）（[MCP 官方指南](https://docs.getoutline.com/s/guide/doc/mcp-6j9jtENNKL)）；内置 MCP server 对存量工作区默认关闭，另提供 collection 级「禁用 AI 索引」控制与 WebMCP（浏览器内 agent 控制）（[企业版更新日志](https://docs.getoutline.com/s/enterprise-releases)）。
- **KM 强项（可借鉴）**：集合/文档树结构、评论与协作、文档历史、模板、权限组；「检索即答 + 来源引用 + 投票反馈」的 RAG 答案交互、「collection 级 AI 索引开关」的隐私治理设计值得借鉴。
- **部署 / 许可证 / 社区**：Docker Compose 自托管（PostgreSQL + Redis，官方提示需 dev-ops 经验）（[自托管指南](https://docs.getoutline.com/s/hosting/doc/hosting-outline-nipGaCRBDu)）；[BSL 1.1 许可证](https://github.com/outline/outline)（自托管免费但限制商用 SaaS）；GitHub 30k+ stars，持续活跃。

### 3. Wiki.js

- **定位与用户**：面向团队 / 企业的通用 Wiki 平台，强调多场景（文档、知识库、手册）与可定制（[官网](https://js.wiki/)）。
- **检索能力**：核心亮点是**可插拔搜索引擎模块**：内置 2 个数据库搜索引擎（零配置）之外，可选 Elasticsearch、Meilisearch、Algolia、AWS CloudSearch、Manticore Search 等云/独立引擎（[模块列表](https://js.wiki/modules)；[Elasticsearch 模块文档](https://docs.requarks.io/search/elasticsearch)）。未见内置向量语义搜索与图片内容搜索。
- **AI 能力**：官方无内置 AI 问答 / RAG；AI 辅助主要由社区工具实现；无官方 MCP server。
- **KM 强项（可借鉴）**：页面树 + 多编辑器（Markdown、所见即所得、Code）、Git 同步、细粒度权限、多语言；「搜索后端可插拔」的模块化设计值得借鉴。
- **部署 / 许可证 / 社区**：Docker / Linux / Windows 多方式部署；[AGPL-3.0](https://github.com/requarks/wiki)；GitHub 28.9k+ stars、100M+ 下载，但[核心开发主要依靠 1 名开发者业余时间](https://blog.requarks.net/)，需注意维护风险。

### 4. BookStack

- **定位与用户**：面向团队的文档库 / 知识库，以「书架 → 书 → 章节 → 页面」的强层级结构组织内容，适合手册、SOP、文档中心（[官网](https://www.bookstackapp.com/)）。
- **检索能力**：自建搜索索引，支持全局 / 书内搜索与[高级搜索语法](https://www.bookstackapp.com/docs/user/search-searching/)：精确短语、标签过滤、多维过滤器、日期过滤、否定排除等。未见向量语义搜索与图片内容搜索（图片/附件仅能按名称等元数据搜）。
- **AI 能力**：**无官方 AI 问答 / RAG，也无官方 MCP server**；社区存在多个 MCP server 项目；作者曾在更新说明中提及探索基于 LLM 的查询系统（[官网博客](https://www.bookstackapp.com/blog/)）。
- **KM 强项（可借鉴）**：极清晰的层级文档树（书架/书/章节/页面）、页面模板与草稿、内置 diagrams.net 绘图、OIDC/SAML2/LDAP/MFA 企业登录、审计日志；「高级搜索语法 + 强层级导航」的组合适合文档库型产品。
- **部署 / 许可证 / 社区**：Docker 或手动 PHP+MySQL 部署（[安装文档](https://www.bookstackapp.com/docs/admin/installation/)）；[MIT 许可证](https://www.bookstackapp.com/)（本表中对商用最宽松的团队 Wiki）；2026-04-28 起全部仓库[从 GitHub 迁移至 Codeberg](https://www.bookstackapp.com/blog/project-migrated-to-codeberg/)（[主仓库](https://codeberg.org/bookstack/bookstack)），项目已 11 年历史、社区改用 Zulip（[11 周年数据](https://www.bookstackapp.com/blog/11-years-of-bookstack/)）。

### 5. TriliumNext Notes

- **定位与用户**：个人知识管理工具，是 Trilium Notes 的社区官方后继，面向重度知识管理用户；免费无付费墙（[官网](https://triliumnotes.org/zh-Hans/)）。
- **检索能力**：全文搜索覆盖标题 / 内容 / 属性，采用渐进式搜索策略（精确结果不足时自动模糊匹配，支持 `~=` 等模糊操作符）（[官方 FAQ](https://docs.triliumnotes.org/user-guide/faq)）；数据模型含 `note_embeddings` / `embedding_queue` / `embedding_providers` 向量表支撑**语义搜索**（[代码架构分析](https://deepwiki.com/TriliumNext/Notes)），API 参考中暴露 embedding 模型管理接口（[API Reference](https://docs.triliumnotes.org/user-guide/advanced-usage/internal-api/api-reference)）；内置 OCR 文本提取，图片内文字可被检索。
- **AI 能力**：**内置 AI/LLM**：4 类提供商——云 API（Anthropic、OpenAI、Gemini、DeepSeek）、订阅制（复用 Claude Code 订阅）、本地/Ollama、OpenAI 兼容网关（[LLM 文档](https://docs.triliumnotes.org/user-guide/llm)、[Providers](https://docs.triliumnotes.org/user-guide/llm/providers)）；助手可结合笔记内容回答（内置 AI chat 侧栏）、通过内置工具代用户搜索/创建/更新笔记（[官网功能说明](https://triliumnotes.org/zh-Hans/)）；**内置 MCP server**：Bearer token 认证（在 Options → ETAPI 创建 REST API token 后于 AI/LLM 设置中配置）（[MCP 文档](https://docs.triliumnotes.org/user-guide/llm/mcp)）。
- **KM 强项（可借鉴）**：无限层级笔记树 + 关系图 + 双向链接、属性（自定义元数据）系统、脚本/自动化、每日笔记、版本历史；「向量表 + embedding 队列/提供者」的内嵌向量化架构、以及「AI 修改留痕回滚」设计值得借鉴。
- **部署 / 许可证 / 社区**：Docker / 桌面 / 服务器部署（[架构文档](https://docs.triliumnotes.org/developer-guide/architecture)）；[AGPL-3.0](https://github.com/TriliumNext/Notes)；GitHub 6k+ stars，社区接手原项目后活跃迭代。

### 6. Obsidian（含 AI / 搜索社区插件）

- **定位与用户**：面向个人的本地 Markdown 笔记（vault）工具，知识工作者 / 学生 / 研究者。
- **检索能力**：核心自带搜索；社区插件 [Omnisearch](https://github.com/scambier/obsidian-omnisearch) 提供基于 BM25 的智能模糊搜索（词干、拼写容错），配合 [Text Extractor](https://github.com/scambier/obsidian-text-extractor)（Tesseract OCR）可实现 **PDF 与图片内文字搜索**；[Smart Connections](https://github.com/brianpetro/obsidian-smart-connections) 提供本地 embeddings 的**向量语义搜索**（Smart Lookup，零配置、无需 API key）。
- **AI 能力**：无官方内置 AI 问答 / RAG，依靠丰富的插件生态：[Copilot](https://logancyang.github.io/obsidian-copilot/) 等支持 RAG 问答、多 LLM 后端与 MCP 集成；社区亦有插件可在 vault 内运行 MCP server；官方 [AI CLI](https://obsidian.md/ai)（2026）是官方自动化接口但不是 MCP。
- **KM 强项（可借鉴）**：双向链接 + 局部图 / 全局图、大纲与 Canvas 白板、标签/属性、日记模板、[2700+ 社区插件](https://obsidian.md/plugins)生态；「本地 embedding + 混合检索（BM25 + 向量）+ OCR 可选」的插件组合方案非常契合本产品目标。
- **部署 / 许可证 / 社区**：本地桌面/移动端应用，无需服务器；应用免费（商用使用鼓励购买 $50/年许可证），Sync（$4/月）与 Publish（$8/月，含图谱+全文搜索）付费（[定价页](https://obsidian.md/pricing)）；插件生态极活跃。

### 7. AFFiNE

## 三、对本产品的关键启示（简）

1. **检索实现分层是主流**：FTS（SQLite FTS5/FTS4、PostgreSQL 全文）承担关键字检索，向量检索多以「本地 embedding + 向量索引」实现（Joplin、TriliumNext、Logseq DB、AppFlowy Vault、SiYuan 3.7），两者混合排序（hybrid）是体验最佳实践。
2. **图片搜索普遍缺失**：图片内文字搜索主要靠 OCR（Tesseract 类）间接实现（Obsidian Omnisearch+Text Extractor、TriliumNext OCR），图片语义（像素/CLIP）搜索在该品类中尚属空白，可作为差异化点。
3. **MCP 成为 AI 智能体接入事实标准**：内置 MCP server 的有 Outline、AFFiNE、TriliumNext、Joplin、SiYuan；通行做法是 Streamable HTTP + token/OAuth 认证 + 默认关闭/只读默认 + 工具粒度开关 + workspace 级凭证（带过期、可撤销）。SiYuan 的 CVE-2026-66012 提醒：MCP 端点必须做角色/权限校验，防止低权限用户调用高危工具。
4. **RAG 问答交互模板**：Outline 的「答案 + 来源引用 + 投票反馈」与「collection 级 AI 索引开关」、AppFlowy 的「Vault 本地 RAG」、Joplin 的「语义结果与全文结果混合」、AFFiNE 的「block/element/frame 定位符」是可直接借鉴的交互与架构范式。
5. **许可证与部署**：自托管品类以 AGPL-3.0 与 MIT 为主，Outline（BSL 1.1）、AFFiNE 后端（EE source-available）、Obsidian（专有）是例外；Docker Compose 为标准部署方式；团队型产品普遍对自托管规模设免费上限（AFFiNE 10 席位）。
