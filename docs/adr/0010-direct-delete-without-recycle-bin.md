# 知识库和文档直接删除，不提供回收站

2026-10-28，按产品要求移除回收站及其恢复、保留期和二次彻底删除流程。

## 决策

文档删除直接清理检索索引、分块及文档记录；不存在其他文档引用时回收文件元数据和字节。知识库删除仅允许所有者操作，默认个人知识库不可删除；删除时同步清理其文档和成员关系。页面在删除前提示不可恢复。

不再保留 `deleteTime`、`prevStatus`、已删除文档状态、恢复接口及回收站页面。公共 `BaseDO.deleted` 仍是其他实体及 MyBatis-Plus 查询使用的通用逻辑删除字段，不属于回收站状态。

## 影响

已有部署通过 SQL017 清理历史已删除对象后移除废弃列，防止字段删除导致旧对象重新可见。历史文件字节只有在不存在正常文档引用时清理。旧 SQL 升级脚本保留供顺序升级，新建数据库直接使用不含回收站字段的 schema。

本决策替代旧 PRD、规格和实现记录中的回收站规则；文档创建只保存排队状态、每十分钟由任务扫描解析的决定继续有效。
